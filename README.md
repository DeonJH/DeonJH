## Featured projects

### Ticket Routing System
Event-driven microservices on Spring Boot 4 + Kafka + Spring AI. LLM-powered classification, skill extraction, and sentiment detection feed a sealed-interface strategy pattern; Kafka Streams handle the routing, with Prometheus / Grafana for observability. JDK 25.

### AI Powered Finance Assistant
LangChain + LangGraph agent backed by FastAPI and Streamlit. Ingests spending CSVs, computes category totals, and answers natural-language questions over a real-time chat UI with persistent conversation memory. LangSmith tracing; GPT-3.5 Turbo.

### Automated Tech News Pipeline
Current-generation news digest. A GitHub Actions workflow runs every Friday, pulls RSS feeds, summarizes with GPT-4.1-mini, and writes a static JSON file consumed by a React component on the portfolio. Zero servers, zero ops.

### Automated Tech News Digest
The original automation — n8n + GPT-4o-mini + Google Sheets pipeline. Replaced by the GitHub Actions version above to cut pipeline complexity, but kept around as a reference implementation.
